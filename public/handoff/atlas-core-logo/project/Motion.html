/// rules & anti-patterns

the short list.

  • Motion is informational. If it doesn't make meaning clearer, delete it.
  • Tabular timings. 120 · 200 · 320 · 480 · 720 ms. Nothing else unless physics.
  • Entrance slow, exit fast. Arrivals breathe. Exits get out of the way.
  • ECG is reserved. Only for PRs, completions, labs posting. Not for nav.
  • No spring-bouncing buttons. We're not a toy.
  • Haptic = motion + tick. Every earned haptic pairs with visible motion.
  • Respect reduced-motion. Rings count-up becomes instant; fades replace slides.
  • One hero per screen. Only one thing animates on entry. The rest is there already.
