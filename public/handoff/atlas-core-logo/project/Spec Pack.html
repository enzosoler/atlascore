/// atlas.core · handoff · spec pack

the spec layer.
how designs become an app.

Four documents that turn 107 designed screens into wiring instructions. Read in order: screen map first (what connects to what), then the data model (what drives each screen), then features (what's considered "done"), then per-screen wiring (what every button does). Bundle alongside the designs in any handoff — to Claude Code, a human team, or both.

data model.
Entities as TypeScript-ish pseudocode. User, Profile, Program, Set, MealLog, Protocol, Lab, Coach — plus derived values + privacy classes.

/ doc 02 · features
features.
Behavior specs in Given/When/Then. Auth, onboarding, training, nutrition, body, protocols, coach, social, platform, coach-side — plus explicit non-goals.
is this done?↗
/ doc 03 · wiring
wiring notes.
Per-screen map of every tap, every read, every emit. Plus the global event bus (set.logged, session.completed, insight.published…) for the parts that glue screens together.
