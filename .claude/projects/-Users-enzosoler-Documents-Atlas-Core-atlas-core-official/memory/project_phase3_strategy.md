Current state: honest but hollow. Audit complete, all blockers fixed, nothing lies anymore.

Next phase: make a small set of things undeniably real.

## The 5 systems to make real (in order):
1. **Workout execution** — start, log sets, save session, see result
2. **Daily System (Today)** — readiness from real data, real recommendation, real action
3. **Nutrition logging** — at least 1 method (manual or photo) producing real output
4. **Body tracking** — weight/measurements with REAL trends
5. **One intelligence moment** — coach, insights, or labs (differentiation layer)

## DO NOT:
- Migrate 72 v2 screens blindly
- Add animations or polish UI
- Implement i18n fully
- Try to complete all features at once

**Why:** The app is clean and honest but not yet compelling. The move is making it useful, reliable, and addictive in core flows.

**How to apply:** Every task should be evaluated against "does this make a core flow real end-to-end?" If not, it's lower priority.
