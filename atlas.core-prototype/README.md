# atlas.core prototype

Run the prototype:

```bash
npm run design:prototype
```

Open Codex in this repo and use the generator prompt:

```bash
codex atlas.core-prototype/generate-screen.txt
```

Relevant files:

- `atlas.core-prototype/screens-lib.jsx`
- `atlas.core-prototype/screens.jsx`
- `atlas.core-prototype/screens-p2.jsx` to `atlas.core-prototype/screens-p12.jsx`
- `atlas.core-prototype/design-canvas.jsx`
- `atlas.core-prototype/prompt-system.md`
