# atlas.core onboarding system

1. `S90_System_Calibration_Entry`
Purpose: frame onboarding as system calibration instead of profile setup.

2. `S91_System_Bio_Baseline`
Purpose: collect the biological baseline that anchors recovery and energy assumptions.

3. `S92_System_Direction`
Purpose: define the dominant control target so the system can resolve tradeoffs.

4. `S93_System_Load_Profile`
Purpose: measure current output and the usable training environment.

5. `S94_System_Recovery_Window`
Purpose: identify recovery margin and sleep/stress volatility.

6. `S95_System_Fuel_Signal`
Purpose: convert nutrition habits into reliability signals.

7. `S96_System_Schedule_Constraints`
Purpose: identify the execution windows that survive the real calendar.

8. `S97_System_Movement_Constraints`
Purpose: encode pain, injury history, and restricted patterns as routing constraints.

9. `S98_System_Adherence_Risk`
Purpose: locate the actual failure mode and decision bandwidth limit.

10. `S99_System_Data_Inputs`
Purpose: connect live telemetry so the system can stop guessing.

11. `S100_System_Reflection`
Purpose: reflect back what the system now understands about the user.

12. `S101_System_Calibration_Plan`
Purpose: let the user set correction speed and control cadence.

13. `S102_System_First_Week`
Purpose: preview the first operating week in concrete actions.

14. `S103_System_State`
Purpose: show the final configured system state.

15. `S104_System_Trajectory`
Purpose: show the predicted trajectory if compliance holds.

16. `S105_System_Today`
Purpose: hand off immediately into a live Today screen with one clear next action.
