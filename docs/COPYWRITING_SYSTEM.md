# Atlas Core Copywriting System
## High-Conversion, User-Centered Language Guide

---

## 🎯 NORTH STAR

**Primary Promise:**
> "Stop guessing your progress."

**Alternative (Contextual):**
> "See what actually works for your body."

**Core Idea:**
Unification + cause-and-effect visibility. Not describing what the product IS, but what the user finally UNDERSTANDS.

---

## 🧠 PRINCIPLES

1. **Lead with the user's gain, not product features**
   - ❌ "AI-powered correlation engine"
   - ✅ "See what changed your results this week"

2. **Use verbs that describe actions, not abstractions**
   - ❌ "Submit" / "Continue"
   - ✅ "Log workout" / "Add meal"

3. **Speak human, not technical**
   - ❌ "Protocols" / "Insights Engine" / "Measurement System"
   - ✅ "Plans" / "Progress insights" / "Body stats"

4. **Create curiosity through contrast**
   - "You're doing everything right — but you don't actually know what's working"

5. **One idea per sentence, one emotion per section**

### Main Navigation

| Old Name | New Name | Rationale |
|----------|----------|-----------|
| Today | **Today** | Keep it. Clear and focused. |
| Workouts | **Training** | "Training" implies purpose and progression |
| Nutrition | **Nutrition** | Keep it. Scientific but accessible. |
| MyDiet | **My Diet** | Keep it. Personal and clear. |
| Protocols | **Plans** | "Plans" is what users actually want |
| Measurements | **Body Stats** | Casual, conversational |
| Lab Exams | **Health Data** | Broad, non-clinical intimidation |
| Progress | **My Progress** | Personal possessive |
| Insights | **What Changed** | Curiosity-driven, outcome-focused |
| Social | **Community** | "Social" is vague; "Community" implies belonging |

### Sub-Features

| Old Name | New Name | Rationale |
|----------|----------|-----------|
| Protocols | Plans | Users "follow plans" — sounds actionable |
| Prescribed Diet | **Coach Diet** or **Prescribed Diet** | Keep "Prescribed" for professional context |
| Prescribed Workout | **Coach Workout** or **Prescribed Workout** | Same as above |
| Manual Workout Plan | **Custom Workout** | "Custom" implies personalization |
| Block Review | **Training Review** | Clearer context |
| Insights Engine | **Progress Insights** | Describes what it does |

## 🎭 TONE & VOICE GUIDE

### Voice Characteristics

1. **Direct** — No fluff, no filler
2. **Empowering** — User is in control
3. **Curious** — Invites exploration
4. **Confident** — Not apologetic about capabilities

### Do's and Don'ts

✅ **DO:**
- Use second person ("you," "your")
- Start sentences with verbs when possible
- Use contractions ("you're," "don't") for conversational tone
- Write like you're talking to a friend who's serious about their goals
- Create white space — short paragraphs, bullet points

❌ **DON'T:**
- Use jargon ("leverage," "synergy," "optimize")
- Be overly formal or stiff
- Use passive voice
- Make the user feel stupid ("Simply click here")
- Overpromise ("Transform your body in 30 days!")

### Emotional Arc

1. **Landing:** Curiosity → Frustration (problem) → Relief (solution)
2. **Onboarding:** Excitement → Confidence → Commitment
3. **In-App:** Clarity → Momentum → Satisfaction
4. **Retention:** Curiosity about own data → Habit formation
