## QUICK TIPS FOR MAXIMUM IMPACT

1. **Lead with the mark**: Use it on cover, close, and 1–2 supporting slides.
2. **Make numbers big**: 50K, 42%, 8.2 — let them speak.
3. **Use white space**: Don't fill every pixel. Breathing room = premium feel.
4. **Show, don't tell**: Use charts, icons, mockups instead of bullet points.
5. **Tell a story**: Problem → Solution → Traction → Ask. Linear narrative.
6. **Be specific**: "50K users" beats "thousands of users." "42% retention" beats "high retention."
7. **Use color strategically**: Sulfur for key numbers, highlights, CTAs. Ink for text. Gray for supporting info.
