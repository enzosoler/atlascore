/// atlas.core · watchOS · Series 10 / Ultra 2 · 45mm + 49mm

not the iPhone, smaller.
a wrist tool.

atlas.core on Apple Watch is a workout companion, not a compressed mobile app. Three things, fast: log a set, see what's next, start a quick log. Everything else lives on the phone. List-based root, page-based glance, full-screen workout. Crown for the one place it earns its keep — weigh-in. No menus deeper than two taps. Black background, OLED honest, sulfur for accents only.

screens.

Nine screens. The whole app. Anything more belongs on the phone.

structure.

List root → page-based glance for "today" → full-screen for active workout. Three nav patterns, used surgically.

root
S1 · Main list. Big-tap rows: today's workout (accent fill = primary CTA), log meal, weigh-in, water. Crown scrolls. Tap = go.
workout flow
List row → S2 · Pre (one button: Start) → S3 · Logging (full-screen, set-by-set) ↔ S4 · Rest timer → … → S9 · Complete. 2 taps from raised wrist to lifting
today glance
Page-based, 3 pages, swipe horizontally: Fuel ring · Week status · Body weight. Reachable via complication tap or app launch.
quick log
List row → S5 · Suggestions (last 3 meals + Custom) or S6 · Weigh-in. One tap from suggestion = logged. No confirmation screen.
notifications
Long-look S8 with Start / Snooze actions. Workout reminders only — no streak, no nag, no marketing.

screen specs.

For each: purpose · interaction · data shown · states.

S1 · Main list
Purpose: root. The 4 things you came for.
Interaction: Crown to scroll, tap to enter. Today's workout always row 1, in accent fill.
States: rest day → row 1 dims to "Rest · recover"; offline → all rows still tappable, queued ops sync later.
S2 · Workout pre
Purpose: commit screen. One affordance: Start.
Data: week·day, name, exercise count, est duration, exercise list (compact).
Interaction: tap Start = haptic .start, transition to S3.
S3 · Logging (HERO)
Purpose: the only place we'd be fired for getting wrong. Log a set without looking twice.
Data: exercise name, set N of M, last performance, current weight × reps.
Interaction: minus / check / plus. Crown adjusts active value (weight or reps — toggled by tap on the number). Check = haptic .success + advance to S4.
States: PR detected → number flashes accent, haptic .success ×2; bodyweight exercise → kg field hidden.
S4 · Rest timer
Purpose: count down. Resume.
Data: ring at % remaining, MM:SS, next set hint.
Interaction: minus 15s / play-pause / plus 15s. At 0:00 → haptic .notification + auto-advance to S3.
Always-On: ring + time stay visible at 1Hz refresh, tinted at 40%.
S5 · Quick meal
Purpose: log a typical meal in one tap.
Data: top 3 frequent meals (per time of day), kcal each, "Custom" footer.
Interaction: tap row = logged. Haptic .click + dismiss to S1. Custom → opens full picker on phone (Handoff).
S6 · Weigh-in
Purpose: capture body weight. The one Crown-driven number screen.
Interaction: Crown = ±0.1 kg. Tap = save (haptic .success). Initial value defaults to last weight.
States: first ever → no delta line; offline → "Will sync when connected."
S7 · Today (page glance)
Purpose: daily check-in. Page 1 fuel · Page 2 week · Page 3 weight.
Interaction: swipe H. Crown is no-op here (paging is for thumbs).
Data: ring + center number + macros / day pips / latest weight.
S8 · Notification (long-look)
Purpose: reminder for scheduled workouts only.
Actions: Start now (deep-link S3) · Snooze 15 min · dismiss.
Suppression: never fires during another workout, never within 30 min of last reminder, never between 22:00–07:00 user time.
S9 · Complete
Purpose: close the loop. Earned, not celebratory.
Data: total sets, duration, PRs detected.
Motion: single ECG-curve scale-in on the check mark (320ms). No confetti.

complications.

The watch face is the front door. atlas.core ships four — designed for clarity, not branding.

// per complication

circular small
FUEL · 42% · ring + percentage. Updates on every meal log + every 15 min via push.
Why: single-tap glance to "am I on track today." Replaces the activity ring people don't fill.
circular small (alt)
WEEK · 2/4 · ring + ratio. Updates after each completed workout.
Why: honest weekly load. No streak emoji.
corner / inline
NEXT · Push A · workout name only.
Why: answer "what's lifting today" without launching anything. Tap = S2.
rectangular
NEXT 6:30 · Push A · 5 ex · 48 min.
Why: the most useful slot. Time, name, scope. Tap = S2.
smart stack widget
Same payload as rectangular complication, but presented in Series 10's vertical stack with relevance hints: .relevance .critical 30 min before workout.

interaction.

Crown, gesture, haptic, voice. Each used only where it earns its keep.

digital crown
  • S6 weigh-in: ±0.1 kg per detent
  • S3 logging: adjusts the active number (weight ↔ reps via tap-to-toggle); ±2.5 kg or ±1 rep per detent
  • S1 list: standard scroll
  • Everywhere else: no-op. The Crown is never a hidden surprise.
gestures
  • Tap: primary action everywhere
  • Horizontal swipe: S7 page navigation only
  • Edge swipe right: system back (S2 → S1, S6 → S1)
  • Long press: not used. Watch users miss it.
haptics
  • .click: tap a list row, log a meal — quick acknowledgment
  • .start: begin workout
  • .success: set logged · weigh saved
  • .success ×2 (paired): PR detected
  • .notification: rest timer hits 0:00 — distinct from system tap
  • Never: on screen entry, on Crown rotation, on Always-On wake
siri / voice
Three intents donated:
  • "Start my workout" → launches today's session
  • "Log lunch" → S5 with meal-time bias
  • "What's next?" → speaks workout name + time
Suggestions surface in Smart Stack at relevant times.

visual.

Type ramp, color, icon usage. Watch-specific — not phone reuse.

type ramp
  • Hero number: SF Pro Rounded · 56–64 · weight 800 · -2 to -2.8 letter-spacing
  • Section title: SF Pro Rounded · 32 · 800 · -1
  • Body / row title: SF Pro · 14–15 · 600–700
  • Meta / caption: SF Pro · 11–12 · 500–700, gray-2 (#8e8e93)
  • Eyebrow: SF Pro · 11 · 800 · 0.4 letter-spacing · uppercase, gray-2
color
  • Background: pure #000 (OLED). Never an off-black gradient.
  • Surface: g6 #1c1c1e for cards, g5 #2c2c2e for list rows.
  • Text: white primary, g2 #8e8e93 secondary. No tertiary tier on watch.
  • Accent (sulfur #e8b500): reserved for the primary CTA, the active ring, and PR moments. Never decorative.
iconography (sf symbols)
  • figure.strengthtraining workout
  • fork.knife meals · scale.3d weigh · drop.fill water
  • play.fill / pause.fill timer · checkmark set done
  • bolt.fill = atlas.core mark in complications and notifications only
spacing
Edge padding 14–16pt · row padding 10×12pt · row corner 16–18pt · card corner 12–14pt. Touch targets ≥ 38pt high.
always-on
S3 + S4 dim to 40%, ring/timer keep updating at 1Hz. Numbers tabular so digits don't shift width on transition.

what we cut.

A watch app is half-as-much, twice-as-fast.

cut entirely
  • Routine browsing / building (phone)
  • Coach chat / video (phone)
  • Body measurements beyond weight (phone)
  • PR gallery, share cards, history graphs (phone)
  • Settings of any kind (phone, paired iPhone app)
  • Sign-in screens — watch inherits auth via Wallet
simplified
  • Today dashboard → 3 swipeable cards, no more
  • Meal log → 3 suggestions or "Custom" hand-off
  • Workout → set-only view; no warm-up calculator, no notes (those exist on the phone for review)
must be instant
  • Wrist raise → see next workout (≤ 1s, complication)
  • Tap from S3 to logged → next set primed (≤ 800ms)
  • Quick meal tap → logged + dismissed (≤ 1s, optimistic write)

smart features.

notifications
  • 30 min before scheduled workout: long-look with Start / Snooze. Quiet hours respected.
  • Rest timer: distinct haptic, no banner (already in app)
  • PR detected: in-session only — never as a push
  • Never: "Don't forget!" / "X day streak!" / "Your friend just…" — none of it
context-aware
  • Time: meal suggestions reorder by time of day (breakfast 6–10, lunch 11–14, dinner 17–21)
  • Activity: if workout HRM detected (CMMotionActivity), S3 stays awake longer between sets
  • Location: at gym → Start workout suggestion in Smart Stack (geofence opt-in, on-device)
handoff
Workout in progress → swiping the phone unlocks directly to S3 mirror. Quick log Custom → opens full meal picker on phone where you left off.
/// rules & anti-patterns

the short list.

  • Two taps from raised wrist to logged. If a flow needs three, push it to the phone.
  • Black background. Always. No gradients. OLED owes us nothing else.
  • Crown is for one number per screen, max. Never hidden behind a tap-to-reveal.
  • Confirmation = haptic, not a sheet. If you have to ask "are you sure?" you've already lost.
  • Accent ≤ one element per screen. The CTA, or the active ring, or the PR — never two.
  • Numbers are tabular. Always. Reps shouldn't dance.
  • No streaks. No flames. No social. Same rule as phone, doubled on watch.
  • Always-On is a contract. The number you saw 30s ago is the same number now — or it has updated truthfully.
