1. Core Philosophy

atlas.core is not a fitness app.

It is a body operating system.

Design must feel:

controlled
minimal
deterministic
system-driven (not decorative)

No “lifestyle”, no “playful”, no “SaaS UI”.

2. Color System (STRICT)
Base
bg-primary: #000000
bg-secondary: #0E0E0E
bg-tertiary: #141414
Text
text-primary: #FFFFFF
text-secondary: #9CA3AF
text-muted: #6B7280
Accent (YELLOW — LIMITED USE)
accent-primary: #F5C518

Allowed ONLY for:

primary CTA
active state
key metric highlight

Forbidden:

labels
large surfaces
background fills
Forbidden Colors
❌ Blue (any)
❌ Beige / cream
❌ Gradient-heavy UI
❌ Mixed theme surfaces
3. Surface System

All UI must use ONLY:

background (black)
card (dark gray)
elevated card (slightly lighter)

Card rules:

border-radius: 16–20px
padding: 16–20px
NO light backgrounds
NO mixed surfaces
4. Spacing System (NON-NEGOTIABLE)

Use ONLY:

8
12
16
24
32
48
Layout rules:
horizontal padding: 20px ALWAYS
vertical rhythm: consistent across all screens
no arbitrary spacing
5. Layout Grid
max width: 420px (mobile frame)
everything aligns to same left edge
no random centering
cards snap to grid
6. Typography
Hierarchy
H1: large, bold (screen title)
H2: section title
Body: standard
Meta: small, muted

Rules:

no excessive weights
no decorative fonts
numbers = dominant (metrics first)
7. Component Rules
Buttons
primary → yellow background
secondary → outline / dark
no blue
no gradients
Cards
dark only
consistent padding
no mixed styles
Lists
tight spacing
subtle separators
no floating chaos
8. Interaction Model

Everything must answer:

👉 “what should I do next?”

No dead screens.
No passive UI.

9. Prohibited Patterns
❌ Blue buttons (seen in workout)
❌ Beige cards (seen in profile/body/workouts)
❌ Mixed alignment (center + left randomly)
❌ Inconsistent spacing
❌ Decorative UI elements
10. Definition of Done

A screen is only valid if:

matches color rules
matches spacing system
aligns to grid
uses only approved components
feels like a system, not a template
